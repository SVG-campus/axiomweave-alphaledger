# Competition wording and differentiation gap matrix

This is a positioning aid from current public team pages, not a ranking of competitors.

| Crowded phrase or pattern | Why it is insufficient alone | AlphaLedger proof point |
|---|---|---|
| Explainable AI | Explanations can be plausible after the fact | Every decision binds exact inputs, policy, action/refusal, and previous hash |
| Risk guardrails | A guardrail claim does not prove it owns execution | AI can only veto; deterministic code is the sole authorization boundary |
| Multi-agent debate | More agents can add latency and correlated confidence | One controller, one writer, bounded advisory lane, explicit abstention |
| Real-time signals | Freshness and feed provenance can be invisible | Input ages, feed labels, pagination, and malformed records fail closed |
| Autonomous trading | Autonomy can hide unreconciled exposure | Exact account pin, leg ownership, open-order state, session clock, and cutoff |
| Options strategies | Complex names can hide unbounded loss | Only same-expiration 1:1 directional debit spreads, with quote-derived max loss |
| Audit logs | Ordinary logs can be edited or omit refusals | Passes and abstentions share a SHA-256-linked receipt chain |

## Selected route

**Tagline:** Proof before profit.

**One-line product:** AlphaLedger turns every options trade—or refusal—into a replayable evidence
receipt.

**Judge-visible differentiation:** Change one fact (freshness, Greek, spread width, account mode,
position ownership, clock, or maximum loss) and watch authorization disappear while the refusal
remains inspectable.

Avoid universal claims such as “the only,” “safest,” “best,” “guaranteed,” or “proven alpha.” The
demo should establish a narrower and stronger result: deterministic evidence-governed mechanics.
